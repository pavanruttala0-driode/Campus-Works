# CampusWorks — Verified Student Project Showcase

> **Build. Verify. Showcase.** 🎓

CampusWorks is a secure college platform where verified students can showcase their completed technical projects in one centralized and trusted platform.

## 🚀 Features

- 🔐 Student login using Roll Number + Password
- 👨‍🎓 Student registration and dashboard
- 📤 Technical project submission
- 🛠️ Technologies and project details
- 💻 GitHub repository link
- 🚀 Live demo/deployment link
- 👨‍🏫 Faculty/Admin project verification
- ✅ Verified project badge
- 🌐 Public project showcase
- 🔎 Search and filter projects
- ☁️ Firebase Authentication
- 🗄️ Cloud Firestore database

## 💡 Problem

Students build useful software, AI/ML projects, applications, and technical solutions, but there is no centralized and trusted platform to showcase their completed and deployed work.

CampusWorks solves this problem by providing a platform where students can showcase their work and faculty/admins can verify that the submitted project genuinely belongs to the student.

## 🔄 How It Works

Student Login  
↓  
Submit Project  
↓  
Faculty/Admin Review  
↓  
Approve / Reject  
↓  
✅ Verified Badge  
↓  
Public Project Showcase
